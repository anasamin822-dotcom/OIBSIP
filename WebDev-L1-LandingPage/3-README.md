# Landing Page - StudyLoop (OIBSIP Web Development, Level 1, Task 1)

A static, responsive landing page for a demo product (StudyLoop, a weekly study planner concept).

- Tech: HTML5 and CSS3 only, no JavaScript
- Sticky navbar with 4 links, hero with headline, subheadline and call-to-action
- Sections: Features (bento grid), How it works, Student testimonials (sample text), CTA
- Footer with placeholder contact and social links
- One colour palette (indigo and cyan), Inter and Space Grotesk fonts
- Responsive with Flexbox and Grid, CSS-only mobile menu, no horizontal overflow

Open `index.html` in a browser.
