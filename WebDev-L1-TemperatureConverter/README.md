# Temperature Converter (OIBSIP Web Development, Level 1, Task 3)

Converts between Celsius, Fahrenheit and Kelvin.

- Tech: HTML5, CSS3, vanilla JavaScript
- Numeric input with validation (empty or non-numeric input shows an error)
- Unit dropdown, Convert button, all three results shown together
- Absolute zero check (below -273.15 C / -459.67 F / 0 K shows a friendly message)

Open `index.html` in a browser.
